# MacBookPro11,4 (15" Mid 2015)

Trackpad: Force Touch, USB (`05ac:0274`), driver bcm5974. No haptic feedback on Linux.
Display: 2880×1800 at 125% fractional scaling.

Verified 2026-10-25 (Ubuntu 26.04, GNOME 50 Wayland): `gnome-trackpad.sh` only (tap-to-click off, click-method fingers). Pointer (flat default, speed 0) and two-finger scrolling felt right at GNOME defaults, so the scroll-factor hwdb and speed changes weren't needed, unlike 13,1.
