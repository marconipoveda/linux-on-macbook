# Shortcut table (show the relevant rows to the person)

| Mac shortcut | What it does on Linux after setup | GNOME sends | KDE sends | Other sends |
|---|---|---|---|---|
| Cmd + any letter/number (C, V, X, Z, A, S, T, W, F, L, N, P, R, ...) | Same as Ctrl + key | Ctrl+key | Ctrl+key | Ctrl+key |
| Cmd+Shift+key, Cmd+Alt+key | Same as Ctrl+Shift/Alt+key | | | |
| Cmd+Tab (hold Cmd, tap Tab) | App/window switcher | Super+Tab | Alt+Tab | Alt+Tab |
| Cmd+` | Next window of the same app | Super+` | Alt+` | Alt+` |
| Cmd+Space | App search | Super+Space (rebound to Activities) | Alt+Space (KRunner) | Super tap (menu) |
| Cmd+Q | Quit/close window | Alt+F4 | Alt+F4 | Alt+F4 |
| Cmd+H / Cmd+M | Hide / minimize | Super+H | Meta+PgDown | (Ctrl+H/M, no standard) |
| Cmd+← / → | Start / end of line | Home / End | | |
| Cmd+↑ / ↓ | Top / bottom of document | Ctrl+Home / Ctrl+End | | |
| Cmd+Shift+arrows | Select to line/document edge | | | |
| Cmd+Backspace | Delete to start of line | Shift+Home, Backspace | | |
| Option+← / → (+Shift) | Jump (select) by word | Ctrl+← / → | | |
| Option+Backspace / Delete | Delete word | Ctrl+Backspace / Ctrl+Delete | | |
| Cmd+Shift+3 | Full-screen screenshot | Shift+Print | | |
| Cmd+Shift+4 / 5 | Screenshot tool | Print | | |
| Ctrl+Cmd+Q | Lock screen | Super+L | | |
| Ctrl+Cmd+F | Fullscreen | F11 | | |

Terminal note: in terminals use Cmd+Shift+C / Cmd+Shift+V to copy/paste; Cmd+C sends Ctrl+C (interrupt).
Right Option is left alone (AltGr) unless the config was generated with --both-option-keys.
