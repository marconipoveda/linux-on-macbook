# MacBookPro11,4 (15" Mid 2015)

- Keyboard is "Apple Inc. Apple Internal Keyboard / Trackpad" (USB `05ac:0274`, hid_apple). `hid_apple.swap_opt_cmd=0`, `fnmode=3`. keyd's `[ids] *` matches it.
- Tested 2026-10-24: Ubuntu 26.04, GNOME 50 Wayland, keyd 2.5.0-5 (binary `keyd.rvaiya`), Spanish (`es`) layout, config generated without `--both-option-keys`. All shortcuts work, and right Option still types AltGr symbols.
